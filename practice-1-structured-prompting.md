Prompt Engineering – Practice 1

Project Overview

This project demonstrates how to create structured prompts that guide AI models toward accurate, relevant, and well-organized responses.

Objective

Understand the five essential components of an effective prompt:

1. Role
2. Task
3. Context
4. Constraints
5. Output format

Exercise 1: Basic vs Structured Prompting

Prompt A:
“Explain diabetes.”

Prompt B:
“Act as a health educator. Explain diabetes to a 12-year-old using simple English. Cover what diabetes is, its common types, and how it affects the body. Use exactly three short paragraphs and avoid complicated medical terms.”

Evaluation:

Prompt B is more effective because it provides a clear role, task, audience, constraints, and output format. Prompt A is too broad and leaves important details unspecified.

Exercise 2: Creating a Structured Prompt

Scenario: Explain climate change to a 10-year-old.

My prompt:

“Act as a climate expert. Explain climate change to a 10-year-old using simple English vocabulary. Cover the main causes and effects of climate change. Use exactly four short paragraphs and avoid complicated scientific terms.”

Evaluation:

The prompt includes all five essential components:

* Role: Climate expert
* Task: Explain climate change
* Context: A 10-year-old audience
* Constraints: Simple English and no complicated scientific terms
* Output format: Exactly four short paragraphs

Exercise 3: AI Response Evaluation

Scenario: An AI produces five paragraphs instead of the requested four, but the information is factually correct and uses simple vocabulary.

Evaluation:

* Factual accuracy: Correct
* Relevance: Correct
* Clarity: Correct
* Instruction-following: Incorrect

Final verdict: The response is partially compliant. It provides accurate information but fails the paragraph-count requirement.

Key Learning

A good prompt reduces ambiguity by clearly communicating what the AI should do and how the response should be presented.

AI responses should be evaluated across separate categories. A formatting mistake should not automatically make factually correct information incorrect.
