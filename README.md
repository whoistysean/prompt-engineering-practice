Prompt Engineering Practice

Project Overview

A beginner portfolio project demonstrating practical prompt engineering skills, structured prompt design, and AI response evaluation.

Learning Objectives

* Understand the five components of effective prompts.
* Write clear and specific instructions for AI models.
* Reduce ambiguity in prompts.
* Evaluate AI responses against given instructions.
